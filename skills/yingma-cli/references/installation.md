# 安装与首次使用

仅在用户要求安装小影马 Agent CLI，或安装后询问下一步如何使用时阅读本文件。

## 安装

命令包包含 `SKILL.md`、本地 `yingma` 命令和参考文档。安装器要求 Node.js 18 或更高版本：

- macOS / Linux：运行 `scripts/install-yingma-cli.sh`。
- Windows PowerShell：运行 `scripts/install-yingma-cli.ps1`。
- Windows CMD：运行 `scripts/install-yingma-cli.cmd`。

安装器将命令放在当前用户目录的 `.yingma/bin` 中，不覆盖已有安装，除非用户明确要求强制更新。根据安装器输出将该目录加入 `PATH`，重新打开终端。

## 安装后的默认动作

安装完成后，只运行：

```bash
yingma doctor
```

`doctor` 仅读取本机 CLI 版本、Node.js 版本、登录态来源和当前目录的项目绑定状态；不读取浏览器凭据、不请求项目数据，也不会写入项目。

向用户返回简洁结论：

1. 是否安装成功，以及 `doctor` 的结论；
2. 是否已登录、是否已绑定项目；
3. 下一步需要用户明确选择登录、检查已有项目，还是开始新的创作任务。

不要输出令牌、验证码、密码或配置文件内容。

若用户询问“现在怎么用”，按 [agent-guidance.md](agent-guidance.md) 的三种方向引导：登录、诊断已有项目，或创建新的 Agent 流水线/无限画布/互动影游方案。不要默认创建项目或开始生成。

## 登录仅在用户确认后进行

网页登录态不会同步到 CLI。只有用户明确要求登录时，运行 `yingma auth login`：CLI 会自动获取并打开图形验证码，再引导完成邮件或短信验证码。验证码图片只保存在本地；认证令牌存于 `~/.yingma/config.json`，或由环境变量 `YINGMA_TOKEN` 提供。

## 开始创作

登录后，用户可以直接以自然语言要求创建产品广告方案、搭建短剧章节画布，或检查已有项目。先读取或预演；创建项目、画布、节点和连线会写入账户，必须取得用户对具体任务的明确授权。生成、渲染、删除和全量导入还必须携带 `--yes`，并在提交前让用户确认目标与费用。
